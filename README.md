## 📅 Diario de desenvolvimento

OBS: Antes da conecção com o github

### Dia 1 - A Conexão e o Primeiro Botão

- Criei um botao usando <input type="button">
- Aprendi a conectar html e javascript usando os id's
- Defini as variaveis e o conteudo principal do html

### Dia 2 - O Sistemas de Pontos

- Conectei o botão com a função de pontos criadas
- Primriros resultados ja a mostra

### dia 3 -Auto clicker

- Aprendi a usar setInterval() entendendo tambem que 1000ms e igual a 1 segundo
- Criei uma area de melhorias
- usei if e else para definir o que fazer

## 📚 O que aprendi

Durante o desenvolvimento, aprendi muitos conceitos como o setInterval(), localStorage() em JavaScript e conceitos como variáveis globais e maneiras de centralização em CSS, entendi as ligações entre HTML,CSS e JS por meio de id's, e aprendi ao finalizar o quão importante e organizar bem o código e declarar nomes legíveis as variáveis e funções.

Em resumo aprendi mais errando do que apenas copiando espero que eu erre mais.
